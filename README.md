# Информационный центр

Статическая страница информационного центра с новостями и бургер-меню.  
Реализована на HTML, SCSS, CSS и нативном JavaScript.

<!-- Скриншот: ./docs/screenshot.png (добавьте файл, чтобы показать превью проекта) -->

## Быстрый старт

Откройте `info-center.html` в браузере или запустите Live Server в редакторе и откройте этот файл.

## Стек

- HTML — разметка страницы `info-center.html`.
- SCSS — исходные стили в `scss/`.
- CSS — готовые стили `style.css` и `blocks/burger-menu.css`.
- JavaScript без фреймворков — скрипты меню и переключателя в `scripts/`.
- SVG, WOFF и WOFF2 — изображения, иконки и файлы шрифтов.

## Возможности

- Бургер-меню с отдельной настройкой для экранов 1725, 1023 и 375 пикселей.
- Отображение новостей в сеточном виде; подготовлены grid- и list-варианты изображений.
- Скрипты бургер-меню и переключателя.
- Изображения новостей подготовлены в вариантах для разных размеров экранов и плотности 2x.
- Адаптивная вёрстка и настройка отображения по коммитам проекта.

## Структура проекта

- `info-center.html` — страница информационного центра.
- `scss/` — исходные стили: блоки страницы и глобальные стили.
- `style.css`, `style.css.map` — CSS и карта стилей.
- `blocks/` — CSS бургер-меню и карта стилей.
- `scripts/` — скрипты меню и переключателя.
- `images/` — SVG-иконки и изображения новостей.
- `fonts/` — файлы шрифта IBM Plex Sans.
- `LICENSE` — лицензия проекта.
